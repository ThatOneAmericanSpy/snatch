# snatch
A simple AUR helper written in bash, built from scraps found on the internet.

<sub>This is a beta project, features are few and in dev!</sub>

# Install

```
git clone https://github.com/ThatOneAmericanSpy/snatch.git
cd snatch
makepkg -si
```

# Use

Download a package
```
snatch -S [package]
```

Update all packages
```
snatch -U
```
